[[Backstage]]

Spotifyが本体とは別に販売する有料プラグイン束。Soundcheck / Insights / RBAC / Skill Exchange の4つからなり、個別購入はできない。セルフホストのBackstageにそのまま載せて使う

- Soundcheck は[[Backstage/Software Catalog]]のエンティティを check で採点する。check を level に、level を track に積み上げることで[[Golden Path]]の遵守度を段階として測り、level内の全checkを通すと certification になる
- Insights はBackstage自体の使われ方（利用者数、plugin別の利用、検索や[[Backstage/Software Catalog]]の操作）を可視化し、導入施策が効いたかを測る
- RBAC はBackstage内の操作とデータへのアクセスを[[RBAC]]で制御する
- Skill Exchange はメンターや[[ペアプログラミング]]の相手、短期の助っ人を社内で募集し合うマーケットプレイスを足す
