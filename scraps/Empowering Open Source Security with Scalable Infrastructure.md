#[[Security]] #[[Continuous Integration]]

[[AWS]] の Mila Zhou（Senior Technical Program Manager）による、OpenSSF ブログの記事。OpenSSF の Premier Member である AWS が、Open Source Promotional Credit Program を通じてオープンソースのセキュリティ基盤に計算資源と資金を提供している取り組みを紹介している。

- クレジットの適用例として、Gradle Build Tool は専用サーバーから [[Amazon/EKS|EKS]] と EC2 のオートスケーリング構成へ移行し、[[Amazon/S3|S3]] で月間約2億ダウンロードの Gradle Plugin Portal を配信している
- クレジットが賄う計算資源は、継続的な [[SAST]] ジョブや性能テストなどスケーラブルな検証に使われる
