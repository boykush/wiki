#[[Security]]

[OpenSSF](https://openssf.org/) の podcast "What's in the SOSS" 第67回（S3E19）。host Yesenia が [[AWS]] の Open Source Program Manager Mila Zhou に、資金・戦略・セキュリティの交差点について聞くエピソード

- Alpha-Omega の支援方針: Alpha は [[Python]] や [[Rust]] のような widely-used な critical project、Omega は単独・少人数メンテナーに依存する long tail project
- Alpha-Omega は Python Security Developer-in-Residence の Seth Larson・PyPI Safety and Security Engineer の Mike Fiedler ら常勤セキュリティエンジニアに資金提供。PyPI では月間約300件のマルウェアに対し quarantine 機能導入で対応時間を数日から1分未満に短縮
- [[Valkey]] を community-driven な open source の精神を体現する例として紹介、中国コミュニティのイベント支援に従事
- OpenSSF Ambassador Program は開発者とセキュリティ専門家のギャップを埋める取り組みで、コミュニティ貢献や public speaking の実績を選考基準とする
