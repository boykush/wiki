[[GitHub]] の Issue テンプレートを YAML で定義し、自由記述の Markdown ではなく入力型と必須検証を持つ Web フォームとして提示する機能（public preview）。回答は Markdown に変換されて Issue 本文になる

- 構造化する層が [[Issue fields]] とは異なり、こちらは repository 単位で Issue 本文の書式を揃えるもので、Issue に付くメタデータのフィールドではない
