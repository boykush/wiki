#[[Security]]

"Unified Security Platform" を標榜する商用 SaaS（カテゴリは ASPM / Application Security Posture Management）。10 種類超のセキュリティスキャンを単一 UI に集約する

- スキャン対象は [[SAST]] / SCA / [[DAST]] / シークレット / [[Infrastructure as Code|IaC]] / [[コンテナ]] / CSPM など。Terraform / CloudFormation / [[Kubernetes]] マニフェストの設定ミス検出にも対応
- AutoFix による修正 PR の自動生成や、Aikido Intel による依存パッケージのマルウェア検出まで検出後の対応も持つ
