[[GitHub Issues|Issue]] のサイドバーにある、その Issue に紐づく Pull Request とブランチの欄。PR 本文の `fixes` のようなキーワードで自動で紐づき、手動でも紐付けられる。紐づいた PR がデフォルトブランチにマージされると、Issue は自動で閉じる
