[[GitHub]] の organization にあるリポジトリを巡回し、各リポジトリに置かれた定義ファイル `catalog-info.yaml` を見つけて [[Backstage/Software Catalog]] に取り込む、catalog plugin の module（`catalog-backend-module-github`）。ファイルを置く作業は残るが、その URL を1件ずつ Backstage に登録する作業が要らなくなる。公式が推奨する取り込み方法

<https://backstage.io/docs/integrations/github/discovery>
