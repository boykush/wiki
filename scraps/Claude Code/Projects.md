#[[Agentic Engineering]]

1つのセッションがコーディネータとして振る舞い、別の並列セッションを作り報告を受け取るようなモード。並列セッションは基本的にクラウド環境で動く

- 並列セッションは[[Claude Code/Claude Code on the web]]と同じクラウドのセッションで、[[Claude Code/Remote Control]]を使えば手元のマシンでも動かせる
