#[[Documentation]]

[[GitHub]] のリポジトリに付く、使い方ガイドや設計メモのような長い文書を置くための区画。README がプロジェクトの概要を伝えるのに対して詳細を受け持ち、会話のための [[GitHub Discussions]] とは文書の置き場として役割が分かれる

- 中身は本体とは別の [[Git]] リポジトリで、clone して手元で編集し push できる
- 2010年に Git ベースの wiki として作り直されたとき、それを動かすライブラリが [[gollum]] として公開された
