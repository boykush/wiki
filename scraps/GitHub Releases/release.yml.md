#[[Continuous Delivery]]

[[GitHub Releases]] のリリースノート自動生成で、label で見出しを出し分けるといった制御を機械的に設定するファイル（`.github/release.yml`）

- 効くのは以後に自動生成されるノートの中身だけで、公開済みの Release のノートや tag・release assets には関わらない
