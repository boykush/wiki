#[[Continuous Delivery]] #[[API Architecture]]

Grab の Lian Yuanlin が同社のエンジニアリングブログに書いた記事（2016-10-18）。乗客アプリ向け API を Rails から [[Go]] へ無停止で移した過程を述べる。エンドポイントを1つずつ移植し、負荷テスト、本番でのシャドウテスト、段階的なロールアウトを通した

- 最初は Rails を複製して前段に Go のプロキシを置き [[gRPC]] でつなぐ近道を試したが、約1か月で捨ててエンドポイント単位の移植に切り替えた
- シャドウテストでは Rails が処理したリクエストと応答の写しを Go へ送って結果を比べる。流す量は [[Redis]] の設定値で絞り、不一致は [[Datadog]] に流した。書き込み系は二重書き込みを避けるため、DB に書かずに書くはずの行を組み立てて実際の行と比べた
- ロールアウトはトラフィックを徐々に切り替える（[[カナリアリリース]]）。割合で指定すると 1% でも [[Elastic Load Balancing]] が溢れたため、秒間リクエスト数で増やし、最後に [[DNS]] を Go 側へ向けた
