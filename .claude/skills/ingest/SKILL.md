# Ingest

新しいページを1件作り、既存のウィキへ接続する。理解はユーザーとの対話で確立し、AIは確立済みの内容だけを記録する。

このウィキはユーザーの理解の記録で、既存ページ群がその現在地。1回のingestで広げる理解は情報源そのものに限り、周辺の概念は既存ページが持っているものとして、説明せずリンクする。

## 境界

- 調査と確認を終えるまでファイルを書かない。
- 一回のingestで作るページは原則1件とする。
- 情報源の要約を作らない。書くのは既存の理解へ足す1件ぶんだけ。
- 既存ページに無い周辺概念は説明を足さず、必要なら次のingestの候補として伝えるにとどめる。
- 対話に現れなかった説明、関連、比較を補完しない。
- 既存ページは、ユーザーが承認した文字どおりの言及のリンク化以外では変更しない。
- ウィキ全体の整理や検査へ作業を広げない。

## 1. 土台を確かめる

既存ページを読むのは、関連を探すためだけでなく、今回書かなくてよいことを決めるため。

1. 情報源を読み、中心となる用語と主張を特定する。URLなら一次情報を優先して取得する。
2. 語を変えながら `mise exec -- scraps search "<query>" --json` で関連ページを探す。
3. `mise exec -- scraps tag list --json` で既存タグを確認する。
4. 関連上位3–8件を `mise exec -- scraps get "<title>" [--ctx "<ctx>"] --json` で読む。
5. 中心の用語を、既存ページがある語と無い語に分ける。前者はリンクで済ませ、後者は今回書かない。

## 2. 接続案を確定する

ファイルを書かずに、次を本文で提示する。

- それが何かを表す要旨1–2文。既存の理解へ足す差分として書く
- タイトル案と、同名衝突時だけ配置先の案
- 既存ページへの接続案とリンク方向
- 既存タグから選んだタグ案

そのうえで判断が分かれる点だけを `AskUserQuestion` で問う。推奨案をそのまま通すのが既定なので、迷いのない項目は問いにしない。

- タグとリンク先のように併存しうるものは `multiSelect: true` にし、推奨する選択肢を先頭に置いて末尾に「(推奨)」を付ける。
- 選択肢は1問4件までなので、候補が多いときは本文の一覧で全体を見せ、問いは判断が要るものに絞る。
- 1回の呼び出しは4問までに収める。超えるなら本文での確認に戻す。

ユーザーの確認または修正を待つ。明示的に対話省略を指示された場合だけ、その指示を確認に代える。

## 3. ページを書く

- 対話で確立した内容だけを書く。
- 略語があれば冒頭の第2階層見出し、次にタグ行、要旨、あれば箇条書き、情報源のURLの順にする。
- 既定は要旨までとし、箇条書きは既存ページとの接続を書くときだけ足す。リンクを持たない説明は、情報源にあっても書かない。
- 既存ページがある語は説明せずリンクする。既存ページが無い語は、その語を説明せずに済む書き方にする。
- 仕様詳細、手順、網羅的な利用例は、情報源の要約になるので転記しない。
- 製品分類や比較は、一次情報で検証できた事実だけを書く。
- ページ参照には `[[Title]]`、既存の横断カテゴリだけに `#[[Tag]]` を使う。
- リンクは具体から抽象へ向け、抽象側から具体例を列挙しない。

## 4. 既存ページからのリンクを確認する

1. 新タイトルで再検索し、候補の `body` を読んで文字どおりの未リンク言及を特定する。
2. 既存リンク内、新しいページ自身、文字どおりの言及がない候補を除外する。
3. 残った言及を文脈と見立て付きで提示し、`AskUserQuestion` を `multiSelect: true` で使ってリンク化する箇所を選んでもらう。候補が4件を超えるときは本文で全体を一覧にし、問いは判断が要るものに絞る。
4. 選ばれた箇所だけを `[[Title]]` または `[[Title|表層形]]` に変換する。

候補がなければ既存ページを変更せずに進む。被リンクは自動計算されるため逆リンクを追加しない。

## 5. 検証する

1. 書いた本文を読み返し、リンクを持たない説明が残っていないか確かめる。
2. 使用したタグが既存タグか、明示的に合意した新タグであることを確認する。
3. `mise exec -- scraps lint --rule broken-link` を実行する。
4. 差分を読み、作成したページと承認済みのリンク以外を変更していないことを確認する。
5. 作成したページ、更新したリンク、今回の変更と無関係な警告を分けて報告する。
